# 可选 GPT 备用任务

此目录提供可移植的任务文本和配置示例，不包含个人自动化 ID、线程 ID、模型设置或连接权限，也不会创建真实任务。

1.6.1 默认按成功登录时间定时恢复，平时不轮询。这里的周期备用检查是另一个可选方案，仅在用户单独明确要求时创建。

在所用助手客户端中建立约每 10 小时运行一次的检查任务，将 [prompt.md](prompt.md) 作为指令，并指定本机源码目录。每次先读取真实 VPN 状态；已经连接就结束，Guard 正在恢复时继续等待。只在明确失效或条件阻塞时考虑备用 UI 恢复。

备用恢复需要解锁桌面、可用且已获授权的电脑操作工具，以及用户自己配置好的 MotionPro/OTP。先阅读 [人工恢复](manual-recovery.md)。无工具或权限、明确失败暂停及账号/网关不匹配时报告阻塞，不扩大权限或反复登录。

模板使用 `install.py --disable-jobs` 明确停用公开版自己的 KeepAlive/看护任务后交接预算；不会要求停止其他 Guard、其他 VPN 或工作任务。原来关闭的恢复功能保持关闭；成功一次也不自动删除用户要求持续保留的检查任务。

[task.example.json](task.example.json) 是说明性数据，字段需要按客户端任务系统适配，不应当作通用 API 请求直接上传。
