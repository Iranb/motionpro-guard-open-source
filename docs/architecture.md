# 恢复流程与持久化状态

## 状态监控

主程序以约 10 秒计时器调用厂商 `vpn_cmdline getstatus`。厂商可能把连接状态作为退出码，不能将退出码 2/6 当作 shell 错误。

| 状态 | 处理 |
| --- | --- |
| 2/6，有 L3 隧道 | 更新状态，保留隧道 |
| 1/3/4，连接或断开过程 | 等待现有过程，不并行提交 |
| 0/7，离线 | 需要连续约 30 秒离线观察后才恢复 |
| 未知或仅桌面连接 | 保留现场，报告待检查 |

断线确认要求观察连续；过长采样间隔和唤醒会重置确认窗口。每次恢复分配一个 episode ID 和 attempt ID，主进程另有 generation ID。

## 登录前检查

检查启用开关、人工接管期、失败暂停和小时预算；静态凭据必须可通过当前签名静默读取。检查本地网络和网关 TCP 可达性，默认站点/账号必须匹配已保存的绑定。

取得 `recovery-control.lock` 后保持至整轮结束；生命周期 `guard.lock` 还防止多实例。若客户端在解锁桌面上正由用户操作，则等待，不覆盖未保存的设置。

## 离线 OTP 与时间

令牌保存于不参与同步的专用钥匙串条目，绑定网关及账号。首次导入只在明确的本机设置操作中读取用户自己的官方令牌，并跨两个周期实时核对。

计算使用 `floor(UnixTime / period)` 作为计数器，HMAC-SHA1、动态截断、六位结果。兼容实现要求 10 字节种子、周期为 30 秒的倍数且在 30–300 秒范围内；这些限制是本适配的条件，不是所有 TOTP 的通用限制。使用系统 Unix 时间，显示时区不参与计算。

官方时间偏移参数的符号契约尚未确认。实现用其绝对值加安全余量形成不确定区间，只有区间两端属于同一计数周期时计算；不猜测相邻口令。比较系统时间增量与单调运行计时，跳变、长采样中断或唤醒后等待稳定。此检查不与服务器校时，不能证明系统绝对时间准确。

未导入离线令牌时可使用原有辅助功能读码路径。已经存在的令牌被拒绝、损坏或绑定不符时停止，不自动切换到另一令牌。离线常规恢复检查新计算和时钟稳定；专门的后台诊断另外要求看到周期推进。

## 临时配置与提交

确认 OTP 和剩余时间后，正常关闭已经离线的官方客户端，等待其退出；不能正常退出则停止，不强杀它。

把原 `autoconnect`、`password2` 和失效会话重连设置存入钥匙串回滚事务。用厂商兼容的配置加密格式写入静态密码、新第二密码和临时启动自连设置。该格式供官方客户端读取，不代替 Guard 的钥匙串保密存储。

真正启动登录前持久扣除一次共享预算，记录提交意图；通过 macOS 原生启动 API 后记录客户端 PID 对应的启动确认。每小时最多两次提交；预算损坏时关闭恢复并保留暂停，不给出新预算。提交后的失败增加连续失败计数，达到两次暂停；普通重试有约 90 秒退避。

## 成功归属

最多等待 120 秒新隧道，过程中约每 2 秒检查。认证必须晚于本轮提交，客户端 PID 必须与 Guard 启动的一致，且没有前台人工操作、进程替换或人工接管期。

归属成立才记录 `guard_connection_confirmed` 并增加 `confirmedSuccessCount`。仅看到连接、启动意图或历史成功数不等于本轮自动恢复成功。官方完整 L3 回调用于独立自然验收。PID 本身没有写入事件日志，归属标记是程序的检查结果，日志不能完全独立重算 PID 判断。

整轮取码和隧道等待持续采样锁屏状态；全程锁屏的确认成功另记 `lockedSuccessDates`。该字段和事件要结合外部锁屏采样及接管证据审查。

## 回滚与看护

连接完成或失败后尝试恢复临时字段。只恢复仍等于本轮注入值的字段，避免覆盖用户在过程中作出的新修改。Qt 客户端退出时可能再次写回缓存，因此回滚事务保留至确认退出后的清理。

看护每约 60 秒检查进程、快照、进度和阶段截止时间。进程停止，或连接正常但 Guard 快照陈旧时，可只启动/重启 Guard；每小时最多三次。活动恢复、人工接管和异常离线状态不强制重启 VPN。`--watchdog-inspect` 只查看，不写健康记录或重启。

## 数据位置

公开版专用目录为 `~/Library/Application Support/MotionProGuardOSS/`：

| 文件 | 用途 |
| --- | --- |
| `status.json` | 当前阶段、心跳、条件与归属结果 |
| `recovery-policy.json` | 开关、提交预算、失败暂停、确认和锁屏计数 |
| `watchdog-health.json` | 看护判断与受限重启历史 |
| `events/YYYY-MM-DD.jsonl` | 字段白名单的事件顺序 |
| `manual-attempt.json` | 备用提交的 pending/结算记录 |

JSON 中 Swift `Date` 数值以 2001-01-01 为起点；转换 Unix 秒需加 `978307200`。事件文件名按 UTC 分日。事件每日限制 2 MiB、保留 30 天，不记录账号、密码、种子或 OTP。
