# 证据、限制与自然验收

状态结论分层：厂商 2/6 证明隧道已连接；具体目标验证证明该资源当时可达；Guard 新提交、认证、客户端归属和确认事件组成自动恢复证据。看见一个新连接不能直接认定是自动登录。

记录观察时间与时区、观察窗口、实时厂商状态、必要的白名单状态。Swift Date 数值以 2001 年为 epoch，转 Unix 秒加 978307200；事件日志和文件名可能使用 UTC。`connectedSince` 可能是观察器起点，不是服务端会话开始。

Guard 认证时间提取只读取日志尾部有限窗口，长会话可能回退到旧认证时间。若要核查真实开始时间，使用本机日志的必要事件时间提取，输出事件种类/时间，不显示原文中的账号、站点或 token。日志时间精度为秒、提交时间含小数时，同秒认证可能保守地无法归属；不要伪造计数或改时间迎合验收。

## 只观察自然断线

1. 保持用户原 VPN、Guard 和备用任务；不要制造断线或登录。
2. 约 10 秒采样厂商状态、脱敏心跳/阶段/进度/截止时间及系统锁屏状态，记录最大采样间隔。若无现成采样权限，说明缺口。
3. 自然会话到期后串联：服务器/客户端断线 → 持续离线确认 → 本轮 OTP 验证 → 本轮提交/启动 → 新认证 → L3 隧道 → 归属确认 → 自动计数增长 → 稳定复核。
4. 锁屏结论另核对全过程锁定、睡眠/唤醒/解锁事件、无人工接管或备用提交。单次锁屏取码诊断不等于全程锁屏登录。
5. 用本轮对应 generation/episode/attempt 关联证据，仅保存在本机私有报告。公共仓库只保存合成示例，不发布真实标识、路径、原始日志或账号。

近期样本不足时给观察窗口与缺失环节。一次自然成功不证明长期稳定；公开版新标识/重新签名/新设备仍需自己的自然验收。小组件展示或辅助功能权限异常不否定已存在隧道。

## 分离故障层次

| 证据 | 判断边界 |
| --- | --- |
| 厂商已连接，但业务拒绝认证 | 先查业务认证或权限，不重连 VPN。 |
| 本地路径离线，公共/网关均不可达 | 本地网络可能是阻塞；需要实际观测，不仅凭图标。 |
| 本地路径可用，目标网关 TCP 超时 | 可能是网关/路径/服务端；尚不足以单独定因。 |
| 令牌可算，钥匙串静态凭据被拒绝 | 自动机制未就绪；取码成功不能代表登录就绪。 |
| 新认证和隧道存在，但归属不确定 | 报告连接成功及归属未知，不计为 Guard 已确认成功。 |
